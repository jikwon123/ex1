분석할 매출 파일을 선택하세요

Excel .xlsx 또는 UTF-8 CSV · 최대 20 MB
월별 날짜 1열 + 기업별 매출 열 형태를 지원합니다.

원본 단위를 확인해 선택하세요. 결과는 모두 억원으로 환산합니다.

01 / UPLOAD

월별 매출 파일

첫 행에 기준월 또는 날짜, 이후 열에 기업별 매출 제목을 넣어 주세요. 날짜는 YYYY-MM, YYYY-MM-DD 또는 Excel 날짜 셀을 지원합니다.

월마다 한 행, 기업마다 한 열이 필요합니다. 합계·총계 열은 제외합니다. 매출은 0 이상의 숫자로 채우고, 누락 월과 중복 월은 정리해 주세요.

02 / ANALYZE

10가지 통계 기법

기술통계, 전년 동월 성장률, 연평균 성장률, 변동성, 이동평균, 선형 회귀, 계절 지수, 상관분석, 이상치 탐지, 단기 예측을 계산합니다.

이 화면에는 분석 결과가 표시되지 않습니다. 파일 검증과 계산이 끝나면 별도 결과 화면에서 그래프와 상세 해설을 확인합니다.

03 / PRIVACY

파일은 사용자가 선택

HTML에는 매출 데이터가 포함되어 있지 않습니다. 파일은 세션 메모리에서만 처리되며 네트워크 연결과 브라우저 저장소를 사용하지 않습니다.

새로고침하면 다시 업로드해야 합니다. 원본 파일은 변경하거나 삭제하지 않습니다. .xls·암호화된 Excel은 지원하지 않습니다.

지원 범위와 파일 읽기 안내

1~30개 기업, 연속된 1~2,400개월을 지원합니다. XLSX는 “월간매출” 시트가 있으면 우선 사용하고, 없으면 첫 시트를 사용합니다. 첫 번째 비어 있지 않은 행이 헤더여야 합니다. 제목 행·병합 헤더는 지원하지 않습니다. Excel 수식은 실행하지 않고 파일에 저장된 계산값만 읽습니다. 계산값이 없으면 Excel에서 다시 계산 후 저장해 주세요.

CSV는 UTF-8 및 쉼표 구분 형식입니다. 데이터 셀의 천 단위 쉼표는 CSV에서 따옴표로 감싸야 합니다. 누락·중복 월이나 빈 매출값은 0으로 추측하지 않고 오류로 알립니다. Excel 읽기는 브라우저의 기본 압축 해제 기능을 사용합니다. 해당 기능이 없는 브라우저는 최신 Chrome/Edge를 사용하거나 CSV로 저장해 주세요.
